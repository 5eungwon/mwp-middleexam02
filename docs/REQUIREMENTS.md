# 공통평가 02 요구사항 추적

기준: 제공된 **ch08. Django와 YOLO를 이용한 침입자 감시 시스템_v1.8.pdf**, 3·6·8–13쪽과 사용자의 제출 요구사항.

| 요구사항 | 구현/증빙 위치 |
| --- | --- |
| 별도 GitHub 저장소 | `https://github.com/5eungwon/mwp-middleexam02` (01 저장소와 별개) |
| Django 서버 | `PhotoBlogServer/` |
| Android 클라이언트 | `PhotoViewer/` |
| YOLO 엣지 클라이언트 | `YOLOv5/` |
| JWT 토큰 획득 / multipart 등록 | `/api-token-auth/`, `/api_root/Post/` |
| 새 객체 출현(0→1) 때만 전송 | `YOLOv5/changedetection.py` 및 단위 테스트 |
| 검출 사진의 웹·모바일 조회 | 실제 브라우저·Android 에뮬레이터 캡처 |
| PythonAnywhere 클라우드 동작 | 이번 코드 배포와 원격 요청이 확인된 경우에만 완료 판정 |
| 추가 편의 기능 1 | 제목·설명 검색과 미확인 필터 |
| 추가 편의 기능 2 | 게시물 확인 처리 및 상태 동기화 |
| Word 보고서 | 루트의 공통평가 02 수행 결과 보고서 |

**원본 양식:** 사용자가 루트에 추가한 `모바일웹서비스 프로젝트_공통평가 02_수행 결과 보고서.docx`의 원본을 `docs/templates/report-template.docx`에 보존한다. 원본 표의 1~10 요구사항을 대조하며, 편의 기능은 서버·클라이언트 행을 구분해 기록한다. 관련증빙 칸에는 캡처를 직접 내장하고 뒤쪽에는 확대본을 추가한다.

실제 YOLO 추론, 로컬 연동, 자동 테스트, Android 실행, 클라우드 검증은 별도 상태로 기록한다. PC 브라우저의 모바일 크기 화면을 Android 실행 증빙으로 사용하지 않는다. 이전 과제의 클라우드 화면을 이번 과제의 배포 성공 화면으로 사용하지 않는다.
